## The entry

> My grandfather, the night before my wedding, said: 'Marry someone you enjoy doing nothing with — you'll spend most of your marriage doing exactly that.'

One sentence, 152 characters. A judge model compares entries pairwise; the line
that carries the most lived truth wins.

## How it works

`main.ts` writes that single string to `/output/entry.txt`. Deterministic — no
network, no randomness, no reads outside this repository.

```sh
node main.ts
cat /output/entry.txt
```
